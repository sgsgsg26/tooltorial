## 1. 🚨 문제 정의 및 MVP 범위 (Problem & Scope)
### 1.1 문제 정의 (Mission)
제조 산업 현장의 핵심인 공작기계 공정에서 정밀함을 좌우하는 '엔드밀' 관리는 여전히 아날로그 방식에 머물러 있습니다.
* **안전 및 보관 문제:** 날카롭고 값비싼 공구들이 분류 없이 일반 공구함에 수북이 겹쳐 보관되어 작업자가 손을 다치거나, 공구끼리 부딪혀 사용 전부터 날이 손상됩니다.
* **주관적 육안 검사의 한계:** 공구의 파손 상태를 작업자의 주관적인 판단에 의존하므로 가공 품질이 일정하지 않으며, 아직 쓸 수 있는 공구를 조기 폐기하여 막대한 경제적 손실을 초래합니다.

### 1.2 MVP 범위표
* **핵심 행동 1문장:** 사용자가 사원증(RFID)을 태그하여 공구를 선택하면, 자판기가 공구를 자동 배출하고 AI가 실시간으로 공구의 파손 상태를 판별하여 화면에 직관적인 피드백을 제공한다.
* **이번에 만든 것 (MVP 포함):** 
  - 웹 브라우저 ↔ 아두이노 직접 제어를 위한 Web Serial API 통신
  - 실시간 웹캠 스트리밍 및 YOLOv26 커스텀 모델(5개 클래스) 기반 상태 판별
  - RFID 태그 인증 및 스텝 모터를 활용한 물리적 배출 자동화 메커니즘
  - **NAVER OGQ마켓 API를 연동한 작업자 친화적 감성 UX 구현**
  - **✨ [NEW] 재고 파악 및 불량률 통계를 위한 실시간 관리자 전용 웹 대시보드**
* **이번에 안 만든 것 (MVP 제외):**
  - DB 연동 회원가입 및 소셜 로그인 (오프라인 RFID 인증으로 속도 및 현장성 확보)

## 2. 💡 핵심 솔루션 및 차별점 (Core Solution & UX)
YOLOv26 비전 AI와 아두이노 하드웨어 제어를 결합하여, **불량 공구를 객관적으로 걸러내고 안전하게 자동 배출하는 스마트 자판기 시스템**입니다.

* **AI 상태 판별:** 웹캠을 통해 공구의 미세 파손 상태를 5단계 클래스로 실시간 객체 탐지합니다.
* **스마트 자동 배출:** Web Serial API를 활용해 웹 브라우저에서 아두이노를 직접 제어하며, RFID 인증을 거쳐 지정된 층의 공구를 스텝 모터로 밀어냅니다.

**✨ [가산점 포인트 1] 실시간 통계 시스템 : 관리자 전용 웹 대시보드 구축**
단순 자판기를 넘어 '스마트 팩토리 시스템'으로 거듭나기 위해 관리자 모드를 추가했습니다.
* **데이터 로깅:** 작업자의 대여 시간, 품목, AI 판독 결과가 실시간으로 서버에 `.csv` 형태로 기록됩니다.
* **재고 및 불량 관리:** 층별 공구 재고 부족 알림(Alert)과 AI 판독 기반의 파손 통계(양품/불량 비율)를 대시보드를 통해 한눈에 모니터링할 수 있습니다.

**✨ [가산점 포인트 2] NAVER OGQ API 연동을 통한 작업자 친화적 UX 구축**
단순하고 딱딱한 산업용 기계를 넘어, 감성적인 UX를 제공하기 위해 **NAVER OGQ마켓 API**를 프론트엔드에 연동했습니다.
* **사원증 태그 리액션:** 공구 대여 시 작업자의 사원증에 귀여운 OGQ 캐릭터 프로필이 노출되어 친근함을 줍니다.
* **대기 시간 및 결과 리액션:** 공구가 배출되는 대기 시간과 AI의 판독 결과(Good/Broken)에 맞춰 랜덤 OGQ 스티커가 팝업되며 작업자에게 직관적인 피드백을 제공합니다.

## 4. 🏗️ 시스템 아키텍처 및 동작 흐름 (Architecture)
본 시스템은 Web(소프트웨어)과 Arduino(하드웨어)가 실시간 양방향 통신하는 구조로 설계되었습니다.

```text
[ 브라우저 웹 UI (Client) ] ──(HTTP REST API)──▶ [ AI 비전 서버 (Flask) ]
  - 공구 층수 터치 선택                               - 웹캠 영상 실시간 캡처
  - 배출 완료 시 OGQ 팝업 애니메이션                    - YOLOv26 실시간 판별 
  - 관리자용 실시간 대시보드 출력                       (양품, 파손 등 5종)
         │                                              - 로그 데이터 저장 (.csv)
 (Web Serial API 통신)
         │
         ▼
[ 하드웨어 제어 (Arduino) ]
  - MFRC522: RFID 태그 인증
  - NEMA 17 스텝 모터 (A4988) : 상하 수직 이동 및 경량 공구 배출
  - NEMA 17 스텝 모터 (L298N) : 고중량 선반 바이트 배출
```

## 5. 🛠️ 기술 스택 (Tech Stack)
* **AI Model:** `YOLOv26n` (커스텀 데이터셋 전이 학습), `OpenCV` (영상 프레임 제어)
* **Backend:** `Python`, `Flask` (YOLO 추론 및 실시간 영상 스트리밍 API 서버)
* **Frontend:** `HTML`, `CSS`, `JavaScript`, `Web Serial API`, `NAVER OGQ API`
* **Hardware:** `Arduino Uno`, `CNC Shield v3`, `L298N 모터 드라이버`, `NEMA 17 스텝 모터`(3ea), `MFRC522 RFID`
* **Data & Environment:** `Roboflow`, `NVIDIA RTX 4060 (CUDA)`

## 6. 🧠 AI 모델 학습 상세 (AI Usage & Training)
단순 사전학습 모델이 아닌, 현장 상황에 맞춘 자체 커스텀 데이터셋을 구축하여 파인튜닝을 진행했습니다.

* **학습 베이스 모델:** YOLOv26n (경량화 모델로 하드웨어 실시간 피드백에 최적화)
* **데이터셋 (Roboflow):** 총 1,062장 (학습 746장, 검증 211장, 테스트 105장)
* **클래스 정의 (5종):** 양품(`good`), 미세 손상(`little`), 파손(`destroyed`), 이중 파손(`double break`), 기타(`qwert`)
* **학습 결과:** 100 Epoch 완주, **mAP50 기준 99.50%**의 높은 정확도 달성 (상세 그래프 및 혼동 행렬은 저장소의 `runs` 폴더 내 참조)

## 7. ⚙️ 하드웨어 트러블슈팅 (Hardware Details)
* **선반 바이트 배출 모터 독립 제어 (L298N 도입):** 초기 설계 시 모든 층을 소형 모터 드라이버(A4988)로 통일하였으나, 4층 선반 바이트의 과도한 무게로 인해 모터 탈조 및 떨림 현상이 발생했습니다. 이를 해결하기 위해 4층만 전력 허용량이 높은 **L298N 모터 드라이버**로 아키텍처를 분리 설계하여 3단계 왕복 배출 알고리즘을 성공적으로 구현했습니다.
* **스텝 모터 쇼트(합선) 및 과열 방지:** 스텝 모터 특성상 대기 중에도 홀딩 토크 유지를 위해 전류를 소모하여 피복이 녹아내릴 듯한 심각한 발열 문제가 발생했습니다. 이를 하드웨어 안전 문제로 인식하고, 모터 회전이 끝난 직후 `digitalWrite(LOW)` 명령을 통해 **대기 전력을 소프트웨어적으로 원천 차단하는 페일세이프(Fail-safe) 로직**을 추가하여 쇼트 및 화재 위험을 100% 해결했습니다.
* **배선 매핑 최적화:** CNC Shield의 X/Y축 물리적 배선 반전 이슈를 소프트웨어적 핀 교차 매핑(STEP_Y=핀2, STEP_X=핀3)으로 해결하여 구동 안정성을 높였습니다.

## 8. 🚀 실행 방법 (How to Run)
1. 본 레포지토리의 `.env.example` 파일을 참고하여 `.env` 파일을 생성하고 `OGQ_API_KEY`를 세팅합니다.
2. 하드웨어 전원을 켭니다. (파워서플라이 12V 3~5A 설정)
3. Arduino IDE를 이용해 `VendingMachineRFID/VendingMachineRFID.ino`를 업로드합니다.
4. 파이썬 가상환경에서 서버를 구동합니다.
   ```bash
   call yolo_env\Scripts\activate.bat
   pip install -r requirements.txt
   python app.py
   ```
5. 브라우저에서 `http://localhost:5000/ogq-vending-ui.html` 에 접속하여 팝업 연동 UI를 확인합니다.
6. `http://localhost:5000/admin` 에 접속하여 실시간 대시보드를 확인합니다.
